# Модуль «Обзор» (YouTube-просмотрщик)

Ветка: `feature/youtube-browser` (от `main`). Опциональный модуль: выключен
по умолчанию, включается в настройках (`Настройки → Вкладка «Обзор»`).

## Что делает

Поиск по YouTube и скачивание прямо из результатов, без переключения в
браузер:

- поиск по ключевым словам → сетка карточек с превью, названием, каналом,
  длительностью и числом просмотров;
- вставленная в поиск ссылка открывается напрямую — канал или плейлист
  разворачивается в список, с кнопкой «Назад» к предыдущей выдаче;
- «Скачать» на карточке → пробинг форматов этого видео → существующий
  `FormatPickerModal` → выбор разрешения → конфиг переключается на это видео;
- «В очередь» — добавляет URL в очередь с текущим конфигом, минуя выбор
  формата;
- «Просмотр» — проигрывает видео во встроенном плеере.

Cookies, прокси и deno берутся из обычных настроек (`Network`-таб), поэтому
приватные, возрастные и доступные только по подписке видео находятся и
скачиваются так же, как и при обычной загрузке.

## Почему не встроенный браузер

Полноценный браузер YouTube внутри приложения не сделать:

- Wails v2 — одно окно и один webview (мультиоконность появилась в v3);
- YouTube отдаёт `X-Frame-Options`/`frame-ancestors` и блокирует показ
  страницы просмотра в iframe;
- официальный IFrame Player API работает, но он только для воспроизведения:
  ссылок на потоки из него не достать.

Поэтому просмотрщик построен на метаданных, которые и так умеет извлекать
yt-dlp, а предпросмотр использует официальный embed. Скачивание при этом
по-прежнему целиком делает yt-dlp — плеер в этом не участвует.

## Устройство

### `internal/jsonutil`
Хелперы чтения «мягкого» JSON от yt-dlp (`String`/`Float`/`Int`/`Int64`/
`Bool`/`Objects`/`Decode`). Вынесены из `downloader/probe.go`, который
теперь тоже их использует, чтобы не держать вторую копию.

### `internal/browse`
- `Search(ctx, cfg, query, limit)` — `yt-dlp -J --flat-playlist ytsearchN:<q>`.
  Если запрос сам является URL, вызывается `Open`.
- `Open(ctx, cfg, url)` — то же самое для канала/плейлиста.
- `Item{ID,Kind,Title,URL,Uploader,Duration,DurationSec,Thumbnail,ViewCount,Live}`,
  `Result{Title,Query,Items}`.
- Таймаут листинга — 60 c, лимит результатов — 100.

**Почему `--flat-playlist`:** без него yt-dlp резолвит полные метаданные
(и все форматы) для каждого результата — это отдельный запрос к экстрактору
на каждое видео, десятки секунд на выдачу. Форматы поэтому ленивые: они
пробятся только для того видео, которое пользователь выбрал, уже
существующим `downloader.Probe`.

**Тонкости парсинга** (покрыты тестами в `browse_test.go`):
- у плоских записей нет поля `thumbnail` — только массив `thumbnails`;
  берётся самый широкий вариант до 640 px, иначе строится
  `i.ytimg.com/vi/<id>/hqdefault.jpg` (только если `id` похож на
  YouTube-идентификатор — 11 символов из `[A-Za-z0-9_-]`);
- имя канала лежит под разными ключами (`channel`, `uploader`,
  `playlist_uploader`, `creator`) в зависимости от экстрактора;
- `_type` у плоских записей всегда `url`, поэтому канал от плейлиста
  отличается по `ie_key: YoutubeTab` + виду URL;
- `null`-записи (недоступные/приватные видео) отбрасываются.

### Слой приложения
- `Service.BrowseSearch` / `Service.BrowseOpen` — тонкие обёртки;
- bound-методы `App.BrowseSearch(cfg, query, limit)` и
  `App.BrowseOpen(cfg, target)` — они и порождают `browse.Result`/`browse.Item`
  в сгенерированном `frontend/src/wailsjs/go/models.ts`;
- настройка `AppSettingsDTO.BrowserEnabled` ↔ `settings.App.BrowserEnabled`.

### Фронтенд
- `components/tabs/BrowseTab.tsx` — строка поиска, лимит, сетка карточек,
  «хлебные крошки» (`trail`) для возврата из канала к выдаче.
  Гонки запросов гасятся счётчиком `requestSeq`: ответ старого запроса
  не перезаписывает более новый.
- `components/BrowsePreviewModal.tsx` — плеер на
  `youtube-nocookie.com/embed/<id>` + кнопка «Открыть в браузере».
  `youtubeEmbedURL` экспортирована и покрыта тестами (watch/youtu.be/
  embed/shorts/live, отсев не-YouTube и мусора).
- `lib/viewCount.ts` — компактный формат просмотров (`1.2K`, `4.5M`).
- Вкладка есть в `TABS`, но `visibleTabs` скрывает её при выключенной
  настройке.

## Что не сделано

- Живая проверка на реальной сети — тесты покрывают парсер и построение
  embed-URL, но не сам вызов yt-dlp.
- Нет пагинации: лимит задаётся до поиска (15/30/50/100), «показать ещё»
  не реализовано.
- Нет истории просмотров и подписок — только поиск и обход
  каналов/плейлистов.
- Предпросмотр не работает для видео с запретом на встраивание — в этом
  случае показывается сообщение и кнопка открытия в браузере.
- Поиск всегда идёт по YouTube (`ytsearch:`). Для других сайтов работает
  только вставка прямой ссылки.
